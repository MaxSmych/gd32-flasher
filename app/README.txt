GD32Flasher — прошивка GD32/STM32 через ST-Link
================================================

ЗАПУСК

  Двойной клик по GD32Flasher.bat

  Устанавливать ничего не нужно: PowerShell уже есть в Windows, OpenOCD лежит
  в папке tools и распаковывается сам при первом запуске (до минуты).


ПЕРВЫЙ ЗАПУСК НА НОВОЙ МАШИНЕ — ДРАЙВЕР ПРОГРАММАТОРА

  Один раз, с правами администратора, ДО того как воткнуть ST-Link:

      tools\stlink-driver\stlink_winusb_install.bat   (правой кнопкой →
                                                       Запуск от имени администратора)

  Признак, что драйвера нет: в логе «Error: open failed».


ПОРЯДОК РАБОТЫ

  1. Подключить программатор к плате: SWDIO → PA13, SWCLK → PA14, GND
     отдельным проводом рядом с сигнальными. Кнопка «Как подключить провода»
     показывает схемы и номера выводов по корпусам.
  2. «Определить чип» — программа сама выберет конфигурацию цели.
  3. «Подключиться».
  4. «Считать дамп» — СНАЧАЛА сохранить то, что уже в чипе.
  5. Выбрать файл прошивки (.bin, .hex или .elf) и «Прошить + проверить».

  Для .hex и .elf поле «Адрес» не используется: такие файлы содержат адреса
  внутри себя. Для .bin адрес нужен, обычно 0x08000000.


ОБНОВЛЕНИЯ

  При запуске программа проверяет, нет ли новой версии, и если есть —
  показывает зелёную кнопку «Обновить до ...». Нажали, дождались, закрыли
  и открыли программу заново.

  Нет интернета или закрыт GitHub — программа просто молчит и работает как
  обычно. Ничего никуда не отправляется, скачивается только сама программа.


ЕСЛИ ЧТО-ТО НЕ ТАК

  Окно не открывается вовсе   — запустить diagnose.bat, он положит отчёт
                                на рабочий стол.
  «Error: open failed»        — не поставлен драйвер (см. выше).
  Связь рвётся                — снизить частоту SWD до 480 кГц, укоротить
                                провода, землю вести рядом с сигнальными.
  Программатор не опознаётся  — вынуть и вставить ST-Link; если он питает
                                плату, дать плате отдельное питание.


ВАЖНО

  «Снять защиту» стирает кристалл целиком при следующей подаче питания.
  Перед этим обязательно снять дамп и убедиться, что файл не пустой.

  Исходники и история: https://github.com/MaxSmych/gd32-flasher
